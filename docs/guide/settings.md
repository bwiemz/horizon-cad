# Settings

## Preferences

**Edit ▸ Preferences...** (**Ctrl+,**):

| Setting | |
|---|---|
| Autosave every | How often documents with unsaved changes are saved for recovery, in minutes; 0 turns autosave off. |
| Undo steps | How many steps Undo keeps for each document; 0 keeps them all. |
| Language | The language of menus, forms and messages. It takes effect the next time Horizon CAD starts. |
| Grid snap spacing | The grid's spacing, for Grid snap. |
| Snap reach | How near the cursor must be for an object snap, in pixels. |
| Unit for new documents | The unit a new drawing or part starts in. |
| Decimal places | How many decimals lengths are shown with. |

Whether each drafting aid (object snap, grid snap, ortho, polar) is on is
kept from one session to the next.

## Units

**Edit ▸ Document Units...** sets the document's unit: millimetres,
centimetres, metres, inches or feet. Lengths are shown in it, and a number
typed without a unit is read in it. Changing the unit changes nothing's
size, and can be undone. The unit is saved with the document.

Any length field takes another unit typed after the number: `2 in`,
`50 mm`, `1' 6"`, `3/4 in`. Angles are in degrees; type `rad` for radians.

## Languages

Horizon CAD is in English, German, Spanish, French, Japanese, Korean and
Chinese. It follows the system's language unless you choose one in
Preferences. The translations other than English are new and are being
checked; see `translations/README.md` in the source to help.
