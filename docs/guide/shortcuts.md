# Keyboard shortcuts

On macOS, **Ctrl** is **Cmd**, and the guide is **Cmd+?** rather than F1.

## Everywhere

| Key | Does |
|---|---|
| **F1** | This guide |
| **Ctrl+K** | Command palette |
| **Ctrl+N** | New drawing |
| **Ctrl+O** | Open |
| **Ctrl+S** | Save |
| **Ctrl+Z** | Undo |
| **Ctrl+Y** or **Ctrl+Shift+Z** | Redo (depends on the system) |
| **Ctrl+D** | Duplicate |
| **Ctrl+G**, **Ctrl+Shift+G** | Group, Ungroup |
| **Ctrl+,** | Preferences |
| **F** | Fit all in the view |
| **Space** | Select tool |
| **Escape** | Cancel the tool's current step |
| **Delete** | Delete the selection |

## Drafting aids

| Key | Does |
|---|---|
| **F3** | Object snap on or off |
| **F8** | Ortho on or off |
| **F9** | Grid snap on or off |
| **F10** | Polar tracking on or off |

## 2D tools

| Key | Tool | Key | Tool |
|---|---|---|---|
| **L** | Line | **M** | Move |
| **C** | Circle | **Shift+R** | Rotate |
| **A** | Arc | **Shift+S** | Scale |
| **R** | Rectangle | **Shift+M** | Mirror |
| **P** | Polyline | **O** | Offset |
| **S** | Spline | **X** | Trim |
| **E** | Ellipse | **Shift+E** | Extend |
| **T** | Text | **B** | Break |
| **H** | Hatch | **W** | Stretch |
| **D** | Linear dimension | | |

While typing a value (a coordinate, a radius, an angle), letters go into the
value, not to these shortcuts.
