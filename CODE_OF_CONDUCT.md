# Code of conduct

Horizon CAD follows the **[Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**, in
its issues, pull requests, discussions and every other project space.

In short: be respectful, assume good faith, and keep criticism about the
work, not the person. Harassment, personal attacks and discriminatory
language are not accepted.

## Reporting

To report behaviour that breaks this code, contact the maintainers
privately through GitHub. Use the private vulnerability reporting form on
the **Security** tab, which reaches the maintainers only, and say that it is
a conduct report. Reports are handled in confidence, and the maintainers
apply the Covenant's enforcement guidelines.
